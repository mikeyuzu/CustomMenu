エミネンス・レコードの達成状態の時に受け取り処理を実装します。
メニューで受け取り可能な項目でエンターを押すと、受け取るかの確認ダイアログを表示し、
「はい」を押すとAPIを呼んで受け取ります。
その後、受け取り済みのダイアログを出します。
受け取り済みのダイアログを消すと、ステータスを更新して、メニュー項目からビックリマークを消して文字色を灰色にする。
サブウィンドウのステータスも受け取り済みにする。

報酬受取のAPI
```
        /// <summary>
        /// エミネンス・レコードの報酬を受け取る
        /// </summary>
        /// <param name="charaId"></param>
        /// <param name="category"></param>
        /// <param name="item"></param>
        /// <returns></returns>
        [HttpGet("ReceiveEminenceRecordReward")]
        public ActionResult<EminenceRecordRewardDestination> ReceiveEminenceRecordReward(int charaId, int category, int item)
```

報酬受け取り先
```
    /// <summary>
    /// 報酬受取先
    /// </summary>
    public enum EminenceRecordRewardDestination
    {
        DELIVERY_BOX = 0,   // ポスト
        KEY_ITEM,           // キーアイテム
        MAGIC,              // 魔法

        MAX
    }
```

受取先によってダイアログのメッセージが変わります。

ポストの場合：ポストから受け取ってください。
キーアイテムの場合：エリア移動後に反映されます。
魔法の場合：エリア移動後に反映されます。
